# Rhetorical Move Registry

Use these stable identifiers in paragraph plans and writing evaluations. A move
describes the work a passage performs; it is not a sentence template.

| ID | Function |
| --- | --- |
| `territory` | establish the bounded research territory or context |
| `problem` | identify the consequential problem without inflation |
| `synthesized_gap` | derive an unresolved issue by comparing supplied evidence |
| `purpose` | state the question, objective, or analytic task |
| `method` | identify the design, material, procedure, or analytic basis |
| `result` | report the supplied finding with quantity and scope intact |
| `answer` | answer the section's research question directly |
| `interpretation` | explain a possible meaning distinct from observation |
| `comparison_dimension` | establish a common dimension for comparing sources |
| `convergence_or_tension` | synthesize agreement, divergence, or uncertainty |
| `alternative_explanation` | consider a source-licensed competing account |
| `limitation` | identify the affected inference and its consequence |
| `evidence_boundary` | state what the available material can and cannot support |
| `bounded_contribution` | state an addition relative to a defined baseline |
| `bounded_implication` | derive an implication proportional to the evidence |
| `research_need` | identify warranted further inquiry without inventing a gap |

Moves may recur, but each paragraph needs one dominant function. Do not add a
move merely to make a section resemble a conventional template.
